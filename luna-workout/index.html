周一 · 胸＋腹 · 晚间网球

训练前热身

  1. 快走或轻松骑车 · 5分钟

    从轻松速度开始，逐渐到身体微热、仍能轻松说话。

  2. 面墙滑臂 · 8次

    面向墙，双臂轻贴墙，从W缓慢上滑到舒适的Y，再放回；不耸肩、不挺腰，肩不适就缩小幅度。

  3. 平板卧推轻重量热身 · 1–2组：先8–10次，再5–6次

    使用远轻于正式组的哑铃，熟悉落下和推起；组间稍休息，不练到累。

正式训练

  1. 平板哑铃卧推
    做 3 组 · 每组 8–12 次 · 组间休息 90 秒

    使用水平卧推凳，脚掌踩稳，头、上背和臀部有支撑。哑铃在胸部两侧，肘与躯干约30–60°；手腕保持中立，缓慢推到胸部上方，不耸肩、不碰撞哑铃。先用轻重量熟悉起落。

  2. 上斜哑铃卧推
    做 3 组 · 每组 10–12 次 · 组间休息 75 秒

    凳子约 20–30°；肘不要完全打开成 90°。

  3. 绳索夹胸 / 蝴蝶机
    做 3 组 · 每组 12–15 次 · 组间休息 60 秒

    想象双臂抱住一个大球；回程控制，不让重量把肩拉走。

  4. 俯卧撑
    做 2 组 · 每组 8–15 次 · 组间休息 60 秒

    身体保持一条直线；难度高就做高位俯卧撑。

  5. 下斜椅下腹 / 屈膝举腿
    做 3 组 · 每组 15–20 次 · 组间休息 60 秒

    下放要慢；腰不要塌回凳面，用腹部把骨盆卷起来。

  6. Dead Bug
    做 2 组 · 每组每侧 8–10 次 · 组间休息 45 秒

    对侧手臂与腿同时伸出、同时收回；腰背保持贴地；脚跟悬空，实际左右交替。腰背离地前缩小幅度。

训练后放松拉伸

  1. 慢走放松 · 2–3分钟

    逐渐放慢，等呼吸平稳后再做下面的拉伸。

  2. 扶墙开胸 · 每侧20–30秒 · 1轮

    单侧前臂扶墙，肘略低于肩，身体轻轻转离墙面；肩不耸起、不挺腰，只到温和牵拉。

  3. 横抱肩拉伸 · 每侧20–30秒 · 1轮

    一侧手臂横过胸前，另一手托住上臂，轻轻带向胸前；不要直接压肘关节，肩保持放松。

  4. 扶凳背阔肌拉伸 · 20–30秒 · 1轮

    双手扶稳固凳面，后退并髋向后移；背部保持自然，缓慢放低胸口，不用腰往下塌。

晚上 · 网球

与白天力量分开安排，尽量间隔约6小时；按疲劳调整强度。

训练前热身

  1. 快走或轻松骑车 · 5分钟

    从轻松速度开始，逐渐到身体微热、仍能轻松说话。

  2. 面墙滑臂 · 8次

    面向墙，双臂轻贴墙，从W缓慢上滑到舒适的Y，再放回；不耸肩、不挺腰，肩不适就缩小幅度。

  3. 椅子坐站 · 8次

    徒手，选稳固椅子，脚掌踩稳，慢坐慢起，膝盖随脚尖自然移动。

  4. 扶支撑提踵 · 10次

    轻扶固定支撑，慢抬脚跟、慢落下，不弹跳，脚踝不左右倒。

  5. 小步侧向移动 · 左右各2趟 · 每趟5–10米

    先侧向走，再轻松小步移动。保持膝盖自然弯曲，不交叉脚、不全速急停。

  6. 小场对拉＋渐进挥拍 · 小场轻松对拉3–5分钟，再做5–10次轻松发球

    从短距离、慢速度开始，逐步扩大到全场；发球逐步增加力量，不一上来全力击球。

网球训练

先轻松对拉，按状态逐步增加强度。

训练后放松拉伸

  1. 慢走放松 · 2–3分钟

    逐渐放慢，等呼吸平稳后再做下面的拉伸。

  2. 扶墙小腿拉伸 · 每侧20–30秒 · 1轮

    双手扶墙，一脚在后；后腿伸直、脚跟踩地、脚尖朝前，身体轻轻前移，不把脚踝向内挤。

  3. 扶支撑大腿前侧拉伸 · 每侧20–30秒 · 1轮

    扶稳支撑，另一手握同侧脚踝，双膝自然靠近；轻收骨盆，站直，不用腰后仰。够不到脚踝就不勉强。

  4. 仰卧大腿后侧拉伸 · 每侧20–30秒 · 1轮

    仰卧，一脚踩地，双手托另一侧大腿后方；缓慢伸膝到温和牵拉，膝可微弯，头背留在垫上。

  5. 横抱肩拉伸 · 每侧20–30秒 · 1轮

    一侧手臂横过胸前，另一手托住上臂，轻轻带向胸前；不要直接压肘关节，肩保持放松。

    选远轻于正式组的重量，先找肩部稳定和拉肘方向；不猛拉、不做到累。

  4. 坐姿划船轻重量热身 · 8次

    轻阻力，躯干不前后摇摆，手柄拉向下肋部。

正式训练

  1. 高位下拉
    做 3 组 · 每组 8–12 次 · 组间休息 75 秒

    先把肩胛往下放，再拉肘；拉到锁骨附近，不要身体后仰借力。

  2. 坐姿绳索划船
    做 3 组 · 每组 10–12 次 · 组间休息 75 秒

    胸口抬起，肘往身后拉；顶端夹背 1 秒。

  3. 单臂哑铃划船
    做 3 组 · 每组每侧 10–12 次 · 组间休息 75 秒

    脊柱保持中立；肘朝髋部方向拉，而不是耸肩。

  4. 反向飞鸟
    做 3 组 · 每组 12–15 次 · 组间休息 60 秒

    重量宁轻；手臂只是“挂钩”，让后肩和上背带动。

  5. 45° 背伸 / 臀腿背伸
    做 2 组 · 每组 10–12 次 · 组间休息 60 秒

    从髋折叠，不要过度反弓腰；顶端身体到一条直线即可。

训练后放松拉伸

  1. 慢走放松 · 2–3分钟

  4. 仰卧单膝抱胸 · 每侧20–30秒 · 1轮

正式训练

  1. 坐姿哑铃 / 器械肩推
    做 3 组 · 每组 8–12 次 · 组间休息 75 秒

    肋骨收住、腰不反弓；推起时不要耸肩。

  2. 哑铃侧平举
    做 3 组 · 每组 12–15 次 · 组间休息 60 秒

    手肘微弯；抬到肩高即可，想象肘带动手。

  3. 后束飞鸟
    做 3 组 · 每组 12–15 次 · 组间休息 60 秒

    胸口稳定，动作慢；不要用斜方肌“耸”起来。

  4. Face Pull
    做 3 组 · 每组 12–15 次 · 组间休息 60 秒

    绳子拉向眉眼位置；肘打开，末端外旋。

  5. Pallof Press
    做 2 组 · 每组每侧 10–12 次 · 组间休息 45 秒

    身体正对前方，双手推出时不要被绳索拉转。

  6. 平板支撑
    做 2 组 · 每组保持 30–45 秒 · 组间休息 45 秒

    臀部和肋骨一起收紧；宁可时间短，也别塌腰。

    重量远轻于正式组，缓慢抬髋，不用腰后仰顶起。

正式训练

  1. 史密斯 / 杠铃臀推
    做 3 组 · 每组 8–12 次 · 组间休息 90 秒

    下巴微收、肋骨别翻；顶端夹臀 1 秒，不要用腰顶。

  2. 罗马尼亚硬拉 RDL
    做 3 组 · 每组 8–10 次 · 组间休息 90 秒

    膝微屈且角度基本不变；髋向后推；哑铃贴腿；背保持中立。下降到大腿后侧拉长即可，不强求触地。

  3. 保加利亚分腿蹲
    做 3 组 · 每组每侧 8–10 次 · 组间休息 75 秒

    前脚踩稳，身体微前倾；膝盖朝脚尖方向，不内扣。

  4. 绳索后踢腿
    做 3 组 · 每组每侧 12–15 次 · 组间休息 60 秒

    骨盆保持正，不靠甩腿；幅度宁可小，也要臀部发力。

  5. 侧卧抬腿 · 髋外展
    做 3 组 · 每组每侧 12–15 次 · 组间休息 60 秒

    侧卧在垫上，头有支撑，下侧腿屈膝稳定，上侧腿伸直；骨盆上下叠好，不向后翻。上侧腿向侧上方抬约20–30°，脚尖朝前，不必追求高度；慢慢落回。左右各完成后休息。先徒手，轻松后再考虑合适阻力。

减脂期训练规则

比“多练”更重要
01

循序增加

同一动作连续两次训练都能完成次数上限、动作稳定且仍有余力，再增加最小重量。周四肩部保持轻至中等强度；如果周三网球后肩部疲劳，减少肩推、飞鸟或面拉组数。

02

控制腿部与腹部负荷

膝盖随脚尖自然移动，不强行向外顶；出现关节疼痛、腹部明显鼓起或盆底不适，减小幅度或停止。反复上背疼痛建议评估。

03

恢复优先

如果到下次训练仍明显疲劳，减少组数或网球强度。如医生已明确限制运动，按其意见调整；避免憋气和极限重量，胸痛或异常气短时停止并就医。

组数与休息进度保存在当前浏览器。全部动作素材已内嵌，无需联网。
